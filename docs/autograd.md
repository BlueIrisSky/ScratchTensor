# 自动求导

自动求导积木用于控制计算图记录、执行反向传播和清空参数梯度。先按[训练演示](demo.md)加载本地扩展；本页的 ScratchDSL 片段放在绿旗事件或自制积木的代码体内。

## 计算图追踪

```sbdsl
scratch-tensor-extension.[设置计算图追踪: <true>]
```

参数是布尔值：

| 值 | 行为 |
| --- | --- |
| `<true>` | 开启追踪，也是初始状态。运算的可求导输入中至少有一个需要梯度时，记录输出与输入之间的求导关系。 |
| `<false>` | 后续运算不再记录求导关系，适合只计算预测结果的阶段。 |

这个开关也控制 Dropout，包括注意力中的 Dropout：关闭追踪时不随机丢弃元素。修改开关只影响之后的运算，不会清空已有计算图或参数梯度。关闭追踪后，运算结果仍会注册为 Tensor；不再使用的结果仍需删除或由同名结果替换。当前没有查询追踪状态的 ScratchDSL 积木。

## 反向传播

```sbdsl
scratch-tensor-extension.[对 Tensor "Loss" 进行反向传播]
```

`"Loss"` 是默认的目标 Tensor 名称；目标必须已经注册，名称不存在会报错并停止当前脚本；通常传入本轮前向计算得到的损失。目标既没有求导来源、也没有开启“需梯度”时，调用直接返回。

反向传播按以下方式执行：

1. 从目标沿已记录的计算图遍历，收集本轮需要求导的运算。
2. 如果目标还没有梯度，使用与目标形状相同的全 1 张量作为初始梯度。目标可以是非标量；这种情况下相当于对目标各元素之和求导。
3. 按依赖顺序反向计算，将梯度累加到开启“需梯度”的输入中。直接创建的可学习参数会保留累加结果，直到手动清空。
4. 清理本轮访问到的、带求导来源的非叶子中间节点：清空求导关系和临时梯度，并从注册表中移除。如果目标也属于这类节点，则只清空求导关系和临时梯度，保留 Tensor 及其数值以便读取。

直接创建的叶子 Tensor 不会被这次清理删除，包括无需梯度的样本和标签。与本次目标无关的计算图也不会被清理。下一轮训练需要重新执行前向计算，不能用已经释放的图再次向原参数传播梯度。

## 清空梯度

```sbdsl
scratch-tensor-extension.[清空所有参数梯度]
```

清空当前注册表中所有“需梯度”的叶子参数的梯度缓存，不修改参数数值。优化器更新不会自动清空梯度；通常在每次更新后调用，避免下一轮继续累加。需要跨多个前向过程累积梯度时，可以等全部反向传播结束并更新参数后再清空。

这个积木不负责释放中间计算图；图的释放发生在反向传播结束时。更新参数的顺序见[优化器](optim.md#一次参数更新)。
