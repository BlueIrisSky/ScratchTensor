# 优化器

优化器更新当前注册表中开启“需梯度”的叶子参数。没有梯度的参数会被跳过，普通数据 Tensor 不会被更新。先按[训练演示](demo.md)加载本地扩展；本页的 ScratchDSL 片段放在绿旗事件或自制积木的代码体内。

学习率、动量、权重衰减和全局学习率缩放系数必须是大于或等于 `0` 的有限数；学习率与缩放系数的乘积也必须有限。Adam / AdamW 的 Beta1、Beta2 必须在 `[0,1)` 内。非法参数会在修改任何权重或优化器缓存之前报错。

## SGD 与动量

```sbdsl
scratch-tensor-extension.[执行 SGD 优化器 学习率: 0.01 动量: 0.9 权重衰减: 0]
```

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| 学习率 | `0.01` | 控制更新步长，实际使用时还会乘以全局学习率缩放系数。 |
| 动量 | `0.9` | 大于 0 时保留并累积历史更新量；设为 0 使用不带动量的 SGD。 |
| 权重衰减 | `0` | 大于 0 时，将“衰减系数 × 当前参数”加到梯度中，再计算更新量。 |

动量缓存按参数保存，连续调用时会沿用。每次调用只更新一步，不会执行前向计算、反向传播或清空梯度。

## Adam 与 AdamW

Adam：

```sbdsl
scratch-tensor-extension.[执行 Adam 优化器 学习率: 0.001 Beta1: 0.9 Beta2: 0.999 权重衰减: 0]
```

AdamW：

```sbdsl
scratch-tensor-extension.[执行 AdamW 优化器 学习率: 0.001 Beta1: 0.9 Beta2: 0.999 权重衰减: 0.01]
```

| 参数 | Adam 默认值 | AdamW 默认值 | 作用 |
| --- | --- | --- | --- |
| 学习率 | `0.001` | `0.001` | 更新步长，同样受全局学习率缩放系数影响。 |
| Beta1 | `0.9` | `0.9` | 梯度一阶矩的历史保留系数。 |
| Beta2 | `0.999` | `0.999` | 梯度平方二阶矩的历史保留系数。 |
| 权重衰减 | `0` | `0.01` | 控制参数衰减，两种优化器的应用位置不同。 |

两者都会保存每个参数的一阶矩、二阶矩和更新步数，并进行偏差修正。Adam 在权重衰减大于 0 时，先把衰减项加到梯度中，再更新矩估计；AdamW 直接按“实际学习率 × 衰减系数 × 当前参数”减少参数值，再应用梯度更新。

数值稳定项固定为 `1e-8`，没有对应的积木参数；直接调用 TypeScript API 时，传入的 `eps` 必须是大于 `0` 的有限数。Adam 和 AdamW 共用同一参数的矩估计与步数，切换这两个积木不会重置状态。它们也不会自动清空梯度。

## 梯度裁剪

```sbdsl
scratch-tensor-extension.[对所有参数执行梯度裁剪 最大阈值: 1.0]
```

最大阈值默认为 `1.0`。积木把所有已注册叶子参数的现有梯度合在一起计算 L2 范数；超过阈值时，按同一比例缩小这些梯度，使总范数降到阈值。没有梯度的参数会跳过，有限阈值小于或等于 0 时不执行裁剪，非有限阈值会报错。

应在反向传播之后、优化器更新之前调用。

## 学习率缩放

```sbdsl
scratch-tensor-extension.[设置优化器全局学习率缩放系数为: 1.0]
```

系数初始值为 `1.0`，对 SGD、Adam 和 AdamW 都生效。实际学习率等于优化器积木中的学习率乘以这个系数。例如，学习率为 `0.01`、系数为 `0.1` 时，实际学习率是 `0.001`。

每次设置都会覆盖原系数。连续两次设为 `0.1`，结果仍是 `0.1`。需要预热或衰减时，在训练循环中按步数修改它；这个积木本身不会安排调度。

## 一次参数更新

假设已经完成本轮前向计算，并得到目标 Tensor `"Loss"`：

```sbdsl
# 先求梯度，再裁剪和更新，最后清空本轮梯度。
scratch-tensor-extension.[对 Tensor "Loss" 进行反向传播]
scratch-tensor-extension.[对所有参数执行梯度裁剪 最大阈值: 1.0]
scratch-tensor-extension.[执行 AdamW 优化器 学习率: 0.001 Beta1: 0.9 Beta2: 0.999 权重衰减: 0.01]
scratch-tensor-extension.[清空所有参数梯度]
```

下一步重新执行前向计算。完整的初始化、训练循环和结果读取见[训练演示](demo.md)。

## 重置状态

```sbdsl
scratch-tensor-extension.[删除所有 Tensor]
```

删除全部 Tensor 时，也会清空 SGD 动量缓存、Adam/AdamW 的一阶矩、二阶矩和步数，并将全局学习率缩放系数恢复为 `1.0`。重新训练时，在创建新参数之前执行。
